# Menhir

Unstyled, accessible UI primitives for SolidJS 2.0, with small and measurable bundles.

## Status

In development and not released yet: version 0.0.0 holds the name on npm. Built so far:

- Components: Checkbox, Separator, Switch, Toggle and Toggle Group.
- Utilities: color mode and theme, each with local-storage and cookie storage.

Each has its own entry point, such as `menhir/switch`. The docs, with a live example and the measured size of each, are at [menhir-ui.com](https://menhir-ui.com); the plan and roadmap are in the [repository](https://github.com/j13n/menhir).
